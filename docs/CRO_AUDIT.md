# Ayurpet CRO Audit

Living document that maps each item in the [CRO Checklist sheet][sheet]
against the current state of the Hydrogen storefront. The companion script
[`scripts/cro_sheet.py`](../scripts/cro_sheet.py) reads this file's `Done` /
`In progress` rows and writes them back to the sheet.

[sheet]: https://docs.google.com/spreadsheets/d/1nH4Y2EUXDKcnlgFTHWE5Dpe2k7wxEz44sWxh_8fpGt0/edit

## How this is structured

Each tab in the sheet has a section below. Within each section the rows are
`<tab-row>: <status>  — <one-line note + file ref>` so future agents can
check both the sheet status and where the proof lives in code.

Statuses match the sheet's `PROGRESS` column:
- `Done` — shipped and verified
- `In progress` — partial; what's done is noted
- `To do` — not started
- `N/A` — doesn't apply (e.g., paid Shopify checkout features we can't change)

Run after editing this file:

```bash
cd /home/support/ayurpet-hydrogen
python3 scripts/cro_sheet.py sync   # writes Done/In progress rows to the sheet
```

## How to extend

When you ship a new CRO item:

1. Add the row to the relevant table above with `Done` and a one-line proof.
2. Run `python3 scripts/cro_sheet.py sync` to push the Done state into the sheet.
3. Commit this file along with the implementation change so the audit always
   matches what's deployed.
